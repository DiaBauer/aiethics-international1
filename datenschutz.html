Privacy information

A summary of technical data processing when accessing this independent research website.

Technical hosting

Accessing this website may involve processing technically necessary connection and server-log data such as IP address, request time, requested resource and browser information. The website is hosted using Vercel.

Locally rendered home-page animation

The decorative wave animation is generated locally in your browser using a JavaScript file hosted with this site and the Canvas API. No third-party animation provider is embedded for this effect. No external scripts or fonts are loaded specifically for it. The animation remains static when your device requests reduced motion.

Communication by email

If you email us, the information you send will be processed to handle your enquiry. Please do not transmit sensitive personal details in unencrypted email.

Analytics and cookies

This website does not implement its own advertising or web-analytics tracking. Infrastructure providers may still process technical connection data. The absence of site-level tracking code does not imply that all service providers retain no technical data.

Controller information

For the responsible party and contact details please consult the legal notice.
